# Hi, I'm Carlos Eduardo 👋

**Professor · Software Engineering Researcher · Developer**

I'm a Professor of Software Engineering at the **Federal Institute of Triângulo Mineiro (IFTM)** and hold a **Ph.D. in Computer Science from the Federal University of Uberlândia (UFU)**.

My work sits at the intersection of **Software Engineering, Code Quality, and Artificial Intelligence**, with a particular interest in understanding and improving **source code readability**.

### 🔬 Research interests

- Software Engineering
- Source Code Readability & Maintainability
- AI for Software Engineering
- Large Language Models for Code
- Static Analysis & Automated Refactoring
- Mining Software Repositories

### 🛠️ Current projects

**JADE — Java Static Analysis Repair**  
A VS Code extension that combines static analysis and Large Language Models to identify and automatically refactor code quality issues.

**AI-Assisted Software Development Research**  
Empirical studies investigating how LLMs and AI coding agents affect code quality, readability, maintenance, and software development practices.

### 🎓 Teaching

### 📚 Selected research

My Ph.D. thesis:

**Code Readability Assessment and Improvement: Human and Automated Perspectives**

My research has explored code readability from three complementary perspectives:

**Assess → Understand → Improve**

including empirical studies with developers, pull requests, static analysis tools, Stack Overflow, and Large Language Models.
