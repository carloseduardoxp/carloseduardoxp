My work sits at the intersection of **Software Engineering, Code Quality, and Artificial Intelligence**, with a particular interest in understanding and improving **source code readability**.

### 🔬 Research

My Ph.D. thesis, *Code Readability Assessment and Improvement: Human and Automated Perspectives*, approaches readability in three steps:

**Assess → Understand → Improve**

using empirical studies with developers, pull requests, static analysis tools, Stack Overflow, and Large Language Models.

**Interests:** Source Code Readability & Maintainability · AI for Software Engineering · LLMs for Code · Static Analysis & Automated Refactoring · Mining Software Repositories

### 🛠️ Current projects

**JADE — Java Static Analysis Repair**  
A VS Code extension that combines static analysis and Large Language Models to identify and automatically refactor code quality issues.

**AI-Assisted Software Development**  
Empirical studies on how LLMs and AI coding agents affect code quality, readability, and maintenance.
